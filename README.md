# 🎲 Path of Dice — Кубик Изгнанника

Telegram Web Mini App в декорациях Path of Exile: кубики вместо оружия, сферы вместо крафта,
Атлас миров с ветвящимися картами и рейд-боссы на всю пати. Рассчитано на компанию из 5–6 друзей,
которые кидают кубик раз в день и спорят, чей билд лучше.

Никаких сборщиков, ORM и фронтенд-фреймворков: чистый Node.js + ES Modules на сервере и
ванильный SPA на клиенте. Состояние живёт в одном JSON-файле, который зеркалируется в
закреплённое сообщение Telegram.

---

## Быстрый старт

```bash
npm install
cp .env.example .env      # заполните хотя бы SESSION_SECRET
npm start                 # http://localhost:3000
```

Откройте `http://localhost:3000` — на localhost доступен гостевой вход, и в шапке появится
переключатель шести профилей-друзей. Telegram-бот для игры не обязателен: он нужен только
для авторизации и кнопки запуска Web App.

```bash
npm test                  # 198 тестов на встроенном node --test
npm run dev               # локальная разработка с попыткой поднять HTTPS-туннель
npm run bot               # только бот, без HTTP-сервера (не требуется)
```

### Переменные окружения

| Переменная | Назначение |
| --- | --- |
| `BOT_TOKEN` | Токен бота из @BotFather. Без него игра работает в гостевом режиме. |
| `ADMIN_ID` | Ваш Telegram ID: получает закреплённый бэкап БД в личку. |
| `SESSION_SECRET` | HMAC-секрет для токенов и персональных подписанных ссылок. **Поменяйте.** |
| `WEBAPP_URL` | Публичный HTTPS-адрес — попадает в кнопку `web_app` бота. |
| `PORT` | Порт HTTP-сервера (по умолчанию `3000`). |
| `TUNNEL` | `1` — поднять бесплатный туннель (cloudflared → localhost.run). |
| `KEEP_ALIVE_URL` | Пинг собственного `/health`, чтобы бесплатный хостинг не засыпал. |
| `ALLOW_DEV_AUTH` | `false` отключает гостевой вход (прод-режим). |
| `DB_PATH` | Путь к JSON-базе, по умолчанию `data/db.json`. |

## Что внутри

### Кубик

| Редкость | Как получить |
| --- | --- |
| Обычный | база из магазина Гвеннен |
| Магический | Трансмутка / Алтерация / Регал |
| Редкий | Регал, Хаос, Экзальт |
| Уникальный | 20 Хаоса у Гвеннен, победа над боссом, розыгрыш рейд-лута |

Шесть баз с уникальными имплиситами: `bone_d6` (+1 к грани), `diamond_d4` (+35% крит-мульти),
`weighted_d8` (переброс единиц), `astral_d6` (+5% шанс редкости), `prismatic_d10` (+6% inc),
`runic_d12` (15% мультистрайк). Каждая база требует убить определённое число боссов.

### Сферы (ровно 11)

Точилка, Трансмутка, Алтерация, Аугментация, Скоуринг, Регал, Хаос, Аннул, Экзальт, Дивайн, Ваал.
Орба Алхимии нет — её работу выполняет Хаос. Ваал даёт один из четырёх исходов: имплисит,
апгрейд в T0, ничего или «кирпич» (осквернение).

### Аффиксы

32 группы модов (16 префиксов + 16 суффиксов), тиры T5…T1 и T0 (вес 0, только от Ваала).
Верстак предлагает 7 рецептов с одним крафтовым модом, включая снятие крафта за 1 Скоуринг;
пассивка `generous_bench` удешевляет рецепты на 20%.

### Бросок дня

1 бросок в день по умолчанию, сброс в 00:00 локального времени. Учитывает Lucky,
мультистрайк, плоские и процентные бонусы, «more», крит по формуле с мультипликатором,
ауры пати от друзей и дроп сфер (2–5+). Урон уходит в общего босса чата. Админ может
менять лимит и сбрасывать кулдауны.

### Атлас 2.0

16 зон T1–T16 в четырёх группах. Ежедневный сундук картографа выдаёт 3–5 белых карт и
5 порталов, Кирак продаёт пустую карту за 3 Трансмутки + 3 Точилки. Десять модов карт
торгуют риском за награду.

Поход по карте — это DAG с развилками: 4/5/6 слоёв по тиру, 1–2 ребра, все ветки сходятся
к боссу. Типы узлов: стая, элита, сундук, святилище, засада и босс. В бою — триада
«атака / защита / ва-банк» и девять боевых сфер, у босса есть интенты, щит на 70%/35% HP и
энрейдж. Отступление сохраняет половину добычи.

Дерево Атласа — 12 пассивок в трёх ветках с точными id и эффектами. Победа на карте даёт
map sustain T+1/T+2, bonus objective (+1 очко Атласа за Magic/Rare/Rare-corrupted),
фрагменты и редкие кубики.

### Рейд

Четыре фрагмента (гидра, химера, феникс, минотавр) в общем Реликварии призывают боссов
с 6000 → 7500 → 9500 HP. Рейд живёт 12 часов, удар раз в минуту, щиты Пустоты на 75/50/25%
(выбиваются максимальными гранями), энрейдж ниже 15%. Live Rally: 3 игрока за 10 минут —
x1.5, 5 игроков — x2.0 и игнор щитов. Лут-банк делится по участникам, MVP дополнительно
получает Экзальт и Дивайн, уникальный кубик разыгрывается через `/api/raid/roll-loot`.

## Архитектура

```
src/
  index.js            Express: статика, REST API, SPA-fallback, /health, /healthz
  auth.js             Telegram initData + HMAC-подписанные ссылки, middleware
  bot.js              grammY: только /start, /help, /web
  diceCard.js         HTML-карточка кубика и клавиатура входа
  cloudStorage.js     бэкап path_of_dice_db.json в закреплённый документ админа
  tunnel.js           cloudflared → localhost.run для локального HTTPS
  store.js            GameStore: вся мутационная логика, миграции, дебаунс-сохранение
  initialSeedDb.json  слепок на 6 друзей
  engine/
    constants.js      редкости, базы, сферы, аффиксы, зоны, моды, пассивки, рейд
    crafting.js       применение сфер, верстак, генерация кубиков
    roll.js           бросок дня, ауры пати, дроп сфер, урон боссу
    atlas.js          карты, победы, дерево Атласа, рейд
    mapCombat.js      DAG похода, ходы, отступление, авто-разрешение
public/
  index.html  styles.css  assets.js  app.js
tests/
  helpers.js  atlas.engine.test.js  atlas.combat.test.js  atlas.store.test.js
  atlas.api.test.js  atlas.ui.test.js
```

**Хранилище.** `data/db.json` создаётся из `src/initialSeedDb.json` при первом старте.
Запись атомарная (temp-файл + `rename`), с дебаунсом и `flushSync` на `SIGTERM`/`SIGINT`.
Если заданы `BOT_TOKEN` и `ADMIN_ID`, файл `path_of_dice_db.json` отправляется как документ
в личку админа, закрепляется (`editMessageMedia`, fallback — `sendDocument` + `pinChatMessage`),
а при старте `restoreDbFromTelegramCloud` подтягивает актуальную копию.

**Авторизация.** Три источника сессии: `initData` из Telegram, персональная ссылка
`?player=<id>&sig=<hmac>` и гостевой режим для localhost. Токен — подписанный HMAC-JSON,
живёт 30 дней. Игровые маршруты проверяют игрока каждый у себя, поэтому неизвестный
`/api/*` честно отвечает 404, а не 401.

**Клиент.** Один HTML-файл: постоянно видимая шапка (лого, переключатель профилей на localhost,
активный изгнанник, 🏠 Хаб, звук, 📖 Кодекс) и шесть полноэкранных секций — Хаб, Кузня/Тайник,
Картографический стол, Дерево Атласа, Алтарь Рейда, Лагерь Пати. Никаких трёхколоночных сеток.
Тёмная готика, Cinzel + Inter, canvas-угольки, синтезированный на Web Audio звук (наковальня,
шаг, Экзальт/Дивайн/T1, крит, сундук, святилище, тревога рейда, Ваал) и лут-баннер в стиле
NeverSink с лучом света. Внешних CDN нет — при отсутствии сети всё деградирует мягко.

## REST API

| Метод | Маршрут | Назначение |
| --- | --- | --- |
| `GET` | `/health`, `/healthz` | статус, число игроков, HP босса, uptime |
| `POST` | `/api/auth/session` | `{initData}` или `{playerId, sig}` → токен |
| `GET` | `/api/auth/me`, `/api/profiles` | текущий игрок; список профилей и `signLink` |
| `GET` | `/api/state?v=N` | полный слепок; при том же `v` — `{unchanged:true}` |
| `POST` | `/api/roll` | ежедневный бросок |
| `POST` | `/api/craft/orb`, `/api/craft/bench` | сферы и верстак |
| `POST` | `/api/inventory/{equip,toggle-lock,buy-base,gamble-unique,salvage}` | инвентарь |
| `POST` | `/api/trade/transfer` | передача сфер другу |
| `POST` | `/api/maps/{craft,buy,start,node,choose-node,turn,retreat,dismiss,run}` | Атлас 2.0 |
| `POST` | `/api/atlas/{point,deposit}` | пассивки и фрагменты |
| `POST` | `/api/raid/{summon,attack,claim,roll-loot}` | рейд |
| `POST` | `/api/quest/claim`, `/api/duel` | задания и дуэли |
| `POST` | `/api/settings/*`, `/api/cheat/*` | админка (вайп — кодовое слово `ВАЙП`) |
| `GET/POST` | `/api/cloud/{status,backup,restore}` | облачный бэкап |

`/api/maps/run` с `{auto:false}` открывает интерактивный поход (возвращает `run`),
с `auto:true` (по умолчанию) — мгновенно считает забег и отдаёт `report`.
Ответы сжимаются gzip, `/api/state` скрывает чужие инвентари, а заголовки разрешают
встраивание в iframe Telegram.

### Бот

Всего три команды, никакой игровой логики:

* `/start` — регистрация игрока и карточка кубика с кнопкой Web App;
* `/help` — краткая справка;
* `/web` — персональная подписанная ссылка на приложение.

Карточка кубика собирается в `src/diceCard.js`, клавиатура — `web_app` + `url`-кнопки
(HTTP допускается только при `TELEGRAM_ALLOW_HTTP=1` для локальной отладки).

## Тесты

```bash
npm test        # node --test tests/*.test.js
```

198 проверок в пяти файлах: движок (редкости, сферы, аффиксы, бросок), боевая система
карт (DAG, ходы, щиты, отступление), хранилище (миграции, дневные лимиты, вайп, дебаунс),
HTTP-API (все маршруты, коды ответов, гостевые ограничения) и UI-контракт (наличие
секций, иконок, экранирование, клавиатура бота, синтезатор).
