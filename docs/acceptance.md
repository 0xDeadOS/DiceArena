# Приёмка: основание и первый тренировочный поход

## Автоматические проверки

| Область                 | Что проверяется                                                                                                                                                    |
| ----------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| Telegram HMAC           | подпись, Unicode, порядок/дубли полей, размер, срок, future timestamp, signed identity/slug                                                                        |
| Членство                | разрешённые статусы, restricted/is_member, fail-closed, coalescing, TTL/LRU                                                                                        |
| HTTP                    | запрет клиентских identity/RNG-полей, строгие схемы и UUIDv4 key, общий лимит 5/с, безопасные ошибки                                                               |
| Бот                     | URL-кнопка, группа/admin, миграция, удаление/права, webhook guard                                                                                                  |
| Чистый FSM              | допустимые переходы, focus/flip/reroll, сохранённый intent, щит/bypass/яд/шипы/вампиризм/слабость, приоритет смерти, bounded log                                   |
| Каталог/карта           | диапазоны 15 аффиксов, 3 базы, качество/бонусы, DAG из 7 глубин, награды/40% settlement                                                                            |
| RNG                     | 256-битный seed, детерминизм по счётчику, разделение доменов, диапазоны/ошибки входа                                                                               |
| PostgreSQL              | SQL всех миграций, 20 параллельных регистраций/стартов, ownership, locks/revision, cached replay/TTL, обе формы rollback, снимок кубика, settlement ровно один раз |
| HTTP ↔ БД               | подписанные запросы проходят настоящий репозиторий, повтор не меняет грань; перезапуск API восстанавливает тот же DTO                                              |
| Клиентские stores       | неизменные nonce/body, double tap, 409/429/5xx, блокировка при неизвестном состоянии, игнорирование поздних ответов старой сессии                                  |
| Chromium desktop/mobile | read-only обзор без API, навигация/грани/сферы, старт/узел/roll/reroll/flip, потеря ответа, stale state, reload, отступление/кошелёк, ширины 320–1440 px           |

UI-тесты подменяют Telegram SDK и HTTP. Тесты бота подменяют Bot API. Интеграционные тесты используют **настоящий PostgreSQL 16**, но membership provider в HTTP↔DB тестах подменён. Это проверка границ по отдельности, **не реальный Telegram smoke-test**. Fixture полного маршрута ускоряет победы уменьшенным HP врагов; она проверяет traversal/settlement, а не баланс сложности. Боевое ядро отдельно тестируется с полными тренировочными HP.

Команды и требования окружения — в [README](../README.md). Проверки должны выполняться после обеих миграций, не после `db push`. В CI дополнительно запускается нативный `prisma migrate deploy`.

## Ручной smoke-test на настоящем боте — ещё не выполнен

Нужны локально настроенные `BOT_TOKEN`, PostgreSQL, обе миграции, зарегистрированный short name Mini App и публичный HTTPS-origin. Токен не должен попадать в issue, чат, screenshot или логи.

### Вход и изоляция

- [ ] `/game` в ЛС не создаёт Room и объясняет запуск из группы.
- [ ] `/game` без admin-статуса бота просит настроить права.
- [ ] `/game` в группе создаёт обычную URL-кнопку с `startapp=r_...`; повтор сохраняет ссылку.
- [ ] Первый вход выдаёт 150 золота, кубик 55 PS, сферы 3/2/1, бодрость 3 и пыль 0.
- [ ] Повторный вход не меняет комплект / ID кубика.
- [ ] Второй участник получает отдельный комплект; один пользователь в двух чатах — независимые профили/походы.
- [ ] Пользователь вне группы не получает доступа по пересланной ссылке.
- [ ] После исключения доступ пропадает не позднее пяти минут; после 24 часов подписи требуется открытие Mini App заново.
- [ ] Миграция в супергруппу сохраняет slug и прогресс; удаление/ограничение бота меняет `canSendMessages` на false.

### Тренировка

- [ ] «Походы» → «Начать тренировку» создаёт один маршрут, не списывает бодрость и не меняет сферы/сумку.
- [ ] Нельзя пропустить глубину, повторно открыть сундук или выйти из активного боя в соседний узел.
- [ ] Намерение показывается до броска. После броска можно закрыть Mini App; повторный вход показывает ту же грань.
- [ ] DIRECT даёт +1 focus до 3; SHIFT не даёт focus; HEAL нельзя конвертировать.
- [ ] FLIP стоит 1 focus, сразу разыгрывает противоположную грань и не возвращает focus.
- [ ] REROLL тратит один заряд и не исполняет намерение/тик эффектов до коммита.
- [ ] Два устройства со старой revision не исполняют один ход дважды: второе получает актуальное состояние после конфликта.
- [ ] Потеря ответа не включает новую команду: «Повторить запрос» использует прежний nonce/body и восстанавливает результат.
- [ ] Привал лечит с ограничением maxHP; сундук/бой добавляют pending loot, но не баланс кошелька.
- [ ] Отступление требует подтверждения; cancel ничего не меняет.
- [ ] Победа над боссом начисляет всю добычу, поражение/отступление — floor 40% каждой валюты. Reload/retry не начисляет повторно.
- [ ] Пыль видна в кошельке; после завершения разрешён следующий тренировочный поход.
- [ ] В обычном браузере карта/бой явно являются примером, действия отключены, API не вызывается.
- [ ] В публичных ответах/браузерной сборке нет seed, RNG-counter, Bot token или внутренних Telegram ID; `initData` не попадает в storage/логи.
- [ ] На iOS/Android Telegram корректны нижняя безопасная зона, прокрутка, диалоги и BackButton.

## Что ещё не считается готовым MVP

- Обычные экспедиции: уровни/дроп, расход бодрости, награды предметами/сферами.
- Смена экипировки, ограничения inventory при добыче, lock/unlock и распыление.
- Крафт шестью сферами, passive-EV/PS evaluator и запрет double spending именно сфер.
- Полный onboarding с крафтом и завершением tutorial-флага.
- Рейды: динамический HP, горны/лимиты атак, конкурентный урон, награды, timeout.
- Рейтинг доказанного PS, outbox delivery и лимит редких анонсов.
- Реальная проверка Bot API / Telegram WebView и production deployment.
