# Приёмка этапа 1

## Автоматические проверки

| Область       | Что проверяется                                                                                                 |
| ------------- | --------------------------------------------------------------------------------------------------------------- |
| Telegram HMAC | подпись, Unicode, порядок полей, дубли, размер, срок, future timestamp, user ID, signed slug                    |
| Членство      | разрешённые статусы, restricted/is_member, fail-closed, coalescing, TTL и LRU                                   |
| HTTP          | только signed identity, запрет лишних identity-полей, per-user rate limit, ошибки без секретов, health          |
| Бот           | URL-кнопка, группа/admin, миграция, удаление/права, проверка компонентов deep link                              |
| PostgreSQL    | реальная SQL-миграция, параллельная выдача, rollback, два чата, FK, CHECK, partial indexes, бодрость, DTO       |
| UI            | явный обзор, отсутствие API в обзоре, пары граней, сферы, диалоги, Telegram header, отказ входа, desktop/mobile |

UI-тесты подменяют Telegram SDK и ответы HTTP. Тесты бота подменяют Bot API. Интеграционные тесты используют настоящий PostgreSQL 16, но membership provider в HTTP↔DB тесте подменён. Это намеренное разделение границ, не полноценный тест реального Telegram.

## Ручной smoke-test на настоящем боте

Нужны локально настроенные `BOT_TOKEN`, PostgreSQL, применённые миграции, зарегистрированный short name Mini App и публичный HTTPS-origin. Токен не должен попадать в issue, чат, screenshot или логи.

- [ ] `/game` в ЛС не создаёт Room и объясняет запуск из группы.
- [ ] `/game` без admin-статуса бота просит настроить права.
- [ ] `/game` в группе создаёт обычную URL-кнопку с `startapp=r_...`.
- [ ] Повторная команда сохраняет ссылку и не создаёт вторую комнату.
- [ ] Первый вход выдаёт 150 золота, костяной кубик 55 PS, сферы 3/2/1.
- [ ] Повторный вход и перезагрузка не меняют комплект / ID кубика.
- [ ] Второй участник получает свой комплект; один пользователь в двух чатах — два независимых профиля.
- [ ] Пользователь вне группы не получает доступа по пересланной ссылке.
- [ ] После исключения участника доступ пропадает не позднее пяти минут.
- [ ] После истечения 24 часов подписи требуется открытие Mini App заново.
- [ ] При миграции в супергруппу slug и прогресс остаются прежними.
- [ ] При удалении/ограничении бота `canSendMessages` корректно становится false.
- [ ] API / web не раскрывают initData, Bot token, bigint Telegram ID или seed.
- [ ] На iOS/Android Telegram работает безопасная нижняя зона и BackButton.

## Что не считается выполненной приёмкой MVP

- Совпадение реального боя с намерениями, фиксация roll/commit при закрытии приложения.
- Проверка double-spending сферы по `Idempotency-Key`.
- Одновременные атаки рейда без lost update, расход горнов, награды и timeout.
- Генерация DAG, дроп, распыление, смена экипировки, крафт, обучающий поход.

Эти сценарии нельзя честно отметить как пройденные до реализации соответствующих сервисов.
